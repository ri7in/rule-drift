# Support

- Usage question or idea: start a GitHub Discussion once enabled.
- Reproducible bug: open a bug report with config reduced to non-sensitive data.
- Security concern: follow `SECURITY.md`, not a public issue.

RuleDrift is maintained on a best-effort basis. Please include the RuleDrift version, Node version, operating system, adapter type, and redacted error output. Never post API keys, credentials, private prompts, or unredacted reports.
